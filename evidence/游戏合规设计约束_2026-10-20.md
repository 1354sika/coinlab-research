# 游戏合规设计约束（草案 2026-10-20）

> 本文是设计约束清单，**不是法律意见**。所有法规条目均未核实原文，落地前须咨询专业律师。

## 一、硬红线（碰了就违法，无讨论空间）

| # | 行为 | 为什么 |
|---|---|---|
| 1 | 游戏币 ↔ 真实货币**双向**兑换 | 直接构成赌博 |
| 2 | 充值 → 抽奖/开箱 → 提现 | 同上 |
| 3 | 用真实货币押注任何随机结果 | 同上 |
| 4 | 实时联网对战 + 押注 | 涉嫌开设赌场 |
| 5 | 抽成玩家之间的对赌 | 同上 |

## 二、软红线（需要版号、容易被拒审）

| # | 元素 | 风险 |
|---|---|---|
| 1 | 场景明确是"赌场" | 题材敏感 |
| 2 | 词汇：筹码 / 下注 / 庄家 / 闲家 / 百家乐 / 轮盘 | 审核关键词 |
| 3 | 真实赌博玩法（21点、德州、骰宝） | 可能被认定宣扬赌博 |
| 4 | 诱导充值、诱导消费 | 未成年人保护 |
| 5 | 无版号在中国大陆发行 | 违法 |

## 三、安全设计（推荐）

| # | 做法 | 说明 |
|---|---|---|
| 1 | **题材改为"实验室/博物馆"** | 玩家是研究员，不是赌徒 |
| 2 | **纯虚拟点数，不可充值、不可兑换** | 无经济价值 = 不构成赌博 |
| 3 | **明确反赌叙事** | 副标题写"为什么赌徒必输" |
| 4 | **Steam 国际平台** | 不走国内版号（但需遵守 Steam 政策） |
| 5 | **不做实时联网对战** | 单机/离线 |
| 6 | **不做抽奖/开箱机制** | 规避"随机付费" |

## 四、我们的素材怎么改包装

| 原始素材 | 包装后 | 依据 |
|---|---|---|
| 赌场 | **概率实验室** | 中性 |
| 赌徒 | **被试 / 研究员** | 中性 |
| 下注 | **实验样本 / 试次** | 中性 |
| 筹码 | **虚拟点数** | 无经济价值 |
| 赌博 | **概率测试** | 中性 |
| 庄家优势 | **系统偏差** | 技术化 |
| 梭哈 / YOLO | **全仓策略** | 金融术语 |
| 止损猎杀 | **流动性收割** | 技术化 |

## 五、参考案例

**《恶魔轮盘》（Buckshot Roulette）为什么合规：**

| 要素 | 它怎么做的 |
|---|---|
| 平台 | Steam（国际） |
| 题材 | 恐怖/心理，不是"赌钱" |
| 货币 | 无任何真实货币、无充值 |
| 玩法 | 俄罗斯轮盘（死亡游戏），不是赌博 |
| 结果 | 玩的是"生死"，不是"输赢钱" |

**关键：它把"赌"变成了"死亡游戏"，而不是"金钱游戏"。**

**我们的素材更好办——因为我们本来就是"研究"，不是"赌"。**

## 六、建议的定位

**《67 倍：一个概率实验室的失败记录》**

- 玩家角色：一个想用算法战胜市场的研究员
- 核心问题：能不能稳定赚钱？
- 答案：不能
- 结局：展示 543 个实验文件里的真实数据

**这个定位下：**
- 没有赌场
- 没有筹码
- 没有真实货币
- 是"科普"不是"赌博"

## 七、诚实边界

1. **所有法规条目均未核实原文**（《网络游戏管理暂行办法》《关于规范网络游戏运营加强事中事后监管工作的通知》等）。
2. 版号政策会变化，2026 年的实际情况需重新确认。
3. Steam 对"赌博题材"的政策也需查最新条款。
4. **本文件不能替代法律意见**，落地前必须找律师。
5. 我本人没有游戏合规经验，以上是基于常见认知的整理。
