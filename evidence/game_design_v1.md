# 《盘》游戏设计文档 v1
## 以游戏设计师视角写的第一版

写作日期：2026-10-20
数据依据：`coinlab/evidence/gambler_third.txt`（941 事件 / 304 币）
状态：**设计提案，未验证可玩性**

---

## 一、体验目标（先于一切）

> **玩家玩完这一局，会跟朋友说：**
> **「我明明知道他要出货了，我还是接了。」**

不是"爽"，是**悔**——而且是"我早该知道"的**结构性后悔**，不是运气不好。

数据支撑（`gambler_third.txt`）：
- 追涨延迟中位 **23 根（1.9 小时）**——跟风者永远晚
- 站岗比例中位 **100%**——接盘的人全程被套
- 顶部换手中位 **18.9%**——庄家在最热闹的时刻出货
- 恐慌阈值中位 **−11.6%**——割肉发生在跌了这么多之后

**全世界只有这一套数据能支撑"你永远慢一步"这个体验。**

---

## 二、核心动词

**接**

一个字。不可撤回。按下去立刻有结果。

**不是**"押"（押是对虚空），**不是**"买"（买是中性词），**是"接"**——
接的是**别人抛出来的东西**。

---

## 三、核心循环（一轮 12 秒）

```
① 盘在涨（数字往上走，屏幕中央）
② 某个人按了「抛」（屏幕闪一下红）
③ 你面前出现「接」与「躲」（两个键，立刻可选，无倒计时）
④ 你按「接」→ 成交价 = 当前价 + 延迟成本
   你按「躲」→ 价格继续走
⑤ 3 秒后：盘继续涨 / 崩掉
⑥ 你被套 / 你赚 / 你庆幸 / 你后悔
```

**一轮 12 秒，没有等待，没有思考期。**

---

## 四、有意义的选择（没有最优解）

| 局面 | 按「接」 | 按「躲」 |
|---|---|---|
| 盘在涨 | 你可能接在顶（亏） | 你看着别人赚（痛） |
| 盘在崩 | 你可能接在底（赚） | 你安全但错过（悔） |

**关键：你永远不知道下一秒是顶还是底——所以两个选择都没有标准答案。**

这就是设计师说的 "meaningful choice"：**没有最优解，只有承担。**

---

## 五、张力曲线

```
开局      →  没人抛，盘慢慢涨，无聊、焦躁
第一次抛  →  "接不接？" 心跳
被套一次  →  你不敢再接，但成本已经在那儿
盘继续涨  →  "我是不是错过了？" 侥幸
第二次抛  →  你接了（报复性接盘）——往往接在顶
```

**曲线不是逐步升高，是"焦躁 → 心跳 → 侥幸 → 冲动"的四段式。**

这就是赌徒的真实心理曲线。

---

## 六、反馈（三通道同时）

| 通道 | 内容 |
|---|---|
| **视觉** | 你的持仓成本 vs 当前价，红/绿数字在跳 |
| **听觉** | 接的瞬间「咔」；被套「嗡」（低频） |
| **画面** | 按下「接」的瞬间，屏幕轻微震动 0.2 秒 |

**没有数字累加动画，没有粒子特效——只有震动、声音、和数字变红。**

---

## 七、失败归因

**是你按的，不是系统坑你。**

屏幕上永远显示：**"你在 X 价位接了 N 份"**——这一行字会一直在，直到你平掉。

---

## 八、2~4 人如何成立

| 人数 | 局面 |
|---|---|
| **2 人** | 甲抛、乙接。甲赚，乙套。下一轮交换角色。 |
| **3 人** | 甲抛，乙和丙抢着接。**接的人越多，甲赚得越多** |
| **4 人** | 两个人抛，两个人接。抛的人互相拆台 |

**关键：人越多，"接"越像"抢"——这就是"人群"。**

---

## 九、表现形式（玩家眼睛里看到什么）

```
第一人称，坐在桌前。

  ┌──────────────────────────┐
  │                          │
  │      盘  1,240           │  ← 数字
  │          ▲ +3.2%         │  ← 一个箭头，不是K线
  │                          │
  └──────────────────────────┘

  你：持仓 0       成本 —        钱 800
  甲：持仓 60                      钱 200
  乙：持仓 20                      钱 900

        [ 接 ]          [ 躲 ]
```

**屏幕上没有：**
- ❌ K 线
- ❌ 图表
- ❌ 指标
- ❌ 历史

**只有：**
- ✅ 一个数字（盘）
- ✅ 一个箭头（涨/跌）
- ✅ 每个人的持仓和钱（公开）
- ✅ 两个键（接 / 躲）

**和信息不对称在哪里：** 你看得到他们的持仓，**看不到他们下一秒要做什么**。

---

## 十、为什么这是"赌"而不是"交易"

| 交易 | 赌 |
|---|---|
| 你分析、你计算、你建仓 | **你只知道"有人抛了"，不知道抛多少** |
| 你可以慢慢想 | **你只有两个键，按了立刻成交** |
| 你平仓离场 | **你被套了就只能拿着** |

---

## 十一、和《恶魔轮盘》的结构差异（不照抄）

| | 恶魔轮盘 | 《盘》 |
|---|---|---|
| 你的动作 | 扣扳机（伤害自己/对方） | **接（接下别人抛的）** |
| 你赌什么 | 下一发是实弹还是空包 | **下一秒是顶还是底** |
| 伤害落在谁 | 你或他（择一） | **接的人（可能是我）** |
| 谁在主动 | 你主动扣 | **别人主动抛，你被动接** |
| 节奏 | 轮流 | **同时（谁都可以抛/接）** |
| 累积的是什么 | 血（掉） | **成本（涨）** |

**它赌"勇气"，我们赌"贪念"。它轮流，我们同时。**

---

## 十三、v2 修订：给玩家「手」（可操作性）

**v1 的缺陷**：只有「接 / 躲」两个键，玩家没有可操作的东西，所以"没有玩法"。

**《恶魔轮盘》的可操作性来自"手"**：枪（2 个动作）+ 4 个道具 = 6 个操作。

**我们也要给"手"。从 `gambler_third.txt` 的数据直接长出来：**

### 基本动作（2 个）

| 动作 | 效果 |
|---|---|
| **抛** | 把手里的货按当前价一半卖出去，价格随之下跌 |
| **接** | 买走别人抛出的货，价格随之上涨 |

### 道具（5 个，每个一句话）

| 道具 | 效果 | 代价 | 数据出处 |
|---|---|---|---|
| **假单** | 挂一张假的大买单，骗别人以为在吃货，引诱他们接 | 花筹码；对手可花筹码**戳穿**（戳穿则假单反噬，你亏） | 启动后 48 根内量能峰值中位 **43.2×**（诱多） |
| **内幕** | 看一眼某个人的真实持仓 | 花筹码 | 顶部换手中位 **18.9%**（出货是可观测的，但要花钱） |
| **锁仓** | 指定一个人，他本回合不能抛 | 花筹码 | 站岗比例中位 **100%**（被套的人动不了） |
| **借货** | 借货卖出（做空），价格跌了再买回 | 价格涨了要高价买回，**亏无上限** | 接盘枯竭比 **0.62**（砸下去没人接，做空成立） |
| **抢先** | 抢在别人按「抛」之前先抛，但你只能抛一半 | 暴露意图，全场看到你在跑 | 追涨延迟中位 **23 根（1.9 小时）** |

### 为什么这就有了可操作性

| 玩家现在能做的 | 变化 |
|---|---|
| v1 | 2 个（接 / 躲） |
| **v2** | **7 个**（抛 / 接 / 假单 / 内幕 / 锁仓 / 借货 / 抢先） |

**每个选项都改局面、都有代价 → 有资源管理、有诈唬、有反制。**

**关键：每个道具都有反制——**
- 假单 → 可以被"戳穿"
- 内幕 → 你花钱他也花钱
- 锁仓 → 他被锁了下一回合会更凶
- 借货 → 他拉盘你就爆
- 抢先 → 你暴露了意图

**这就是"石头剪刀布"式的手感：没有无敌的招。**

### 2~4 人怎么成立

| 人数 | 局面 |
|---|---|
| **2 人** | 甲用假单诱乙接；乙花筹码戳穿；甲改用抢先跑；乙借货做空 |
| **3 人** | 甲假单，乙真接，丙戳穿 —— 三方各怀鬼胎 |
| **4 人** | 两两结盟假打，随时背刺 |

**人数越多，"谁在骗谁"越难算——但这不需要很多人才成立，2 人就够。**

### 屏幕长什么样（v2）

```
  ┌──────────────────────────┐
  │      盘  1,240  ▲3.2%     │
  └──────────────────────────┘

  你：货 0     钱 800    道具：假单×1 内幕×2
  甲：货 60              道具：未知
  乙：货 20              道具：未知

  [抛] [接] [假单] [内幕] [锁仓] [借货] [抢先]
```

**7 个图标，一句话说明（悬停/长按出说明），不用背。**

## 十二、诚实边界

1. **这是设计提案，没有任何可玩性验证**——没做过原型、没测过、没人玩过。
2. `gambler_third.txt` 的数据来自 941 个事件、304 币、单一历史样本，**样本外稳定性未知**。
3. "12 秒一轮"、"两个键"、"屏幕震动"都是**凭设计师直觉定的数字**，没测过。
4. "2~4 人"的博弈平衡**完全没有算过**——很可能 3 人比 2 人明显更有利，或者抛的人永远占优。
5. 我没读过 `gambler_memory` / `stophunt` / `blind` / `crowd` / `psych` / `odds` 的内容，**不知道其他场景能否复用这个骨架**。
6. 这个设计**没有解决"玩家第一次玩会不会看不懂"的问题**——需要原型测试。
