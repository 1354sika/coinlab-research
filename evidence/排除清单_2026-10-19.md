## 一、先回答最直接的诱惑：反着做行不行？

**不行。而且我们有数据说明为什么不行。**

| 版本 | 度量 | REAL | SHUF（打乱） | 方向 |
|---|---|---|---|---|
| v2 三头网络 | AUC | **0.5225** | 0.4888 | 微正（不是负） |
| v4 μ+σ | IC | **+0.0005** | +0.0023 | 微正（不是负） |
| v5 只用 σ | 低波−高波收益差 | 8 币中 3 正 / 4 负 / 1 平 | — | 不一致 |

**关键：反着做的前提是"稳定的负 alpha"。我们拿到的是"零 alpha"，不是负 alpha。**

```
反做收益 = −alpha − 2×fee = 0 − 0.04% = −0.04% / 笔   → 稳定亏
```

如果 alpha 是 −5%（显著负），反做能赚 4.96%。
实测 alpha 是 0.05%（≈0），反做等于多付一笔手续费。

**这条本身就排除了一个诱惑：看到模型亏钱就想反着做。**

## 二、真正能反向利用的三样东西

### 1. 负面清单（"不用再试"）

| 已排除的假设 | 排除它的证据 | 什么情况下才值得重试 |
|---|---|---|
| 1m 单币价格量 → 预测方向 μ | IC +0.0005（v4）；AUC 0.52（v2） | 换信息源 |
| 1m 单币价格量 → 预测未来机会 | AUC 0.5225 vs 打乱 0.4888（v2） | 换信息源 |
| 网络容量不够 / 模型太弱 | v3 MSE 0.736→0.273（网络明明学到了） | — 已排除 |
| 赔率单独可以产生 alpha | v5 低波≠高收益，8 币方向不一致 | 赔率 + 新条件变量 |
| 梯度 / 损失设计错 | v1 修好后（v4 改 NLL）仍然失败 | — 已排除 |

### 2. 门槛校准（"什么算失败"的量化标准）

这四条是五版逼出来的，**以后任何新模型先过这四道闸，不过就别跑回测**：

- **AUC < 0.55** ⇒ 无预测力（v2：0.5225）
- **IC < 0.01** ⇒ 无方向 alpha（v4：0.0005）
- **SHUF ≥ REAL** ⇒ 记的是噪声，不是结构（v1：1.30 > 0.87）
- **低波/高波收益差方向不一致** ⇒ 赔率不带 alpha（v5：3/8）

### 3. 对照组（SHUF 必须存在，不是可选项）

v1 就是靠 **"SHUF 1.3011 > REAL 0.8708"** 才发现模型停在初始化点。

**没有 SHUF，v1 会被误读成"接近打平"——实际是"完全没有在学"。**

这一条是五版里最贵的教训：**一个会亏钱的模型，比一个不动的模型更容易被误读成"有信号但用错了"。**

## 三、反向利用真正告诉我们的：该换信息，不是该换模型

五版独立失败，每次排除一个假设 ⇒ 是五次独立的贝叶斯更新：

```
1m 单币价格量
  ├─ 每根连续仓位      v1 ❌
  ├─ 三头机会检测      v2 ❌
  ├─ 自编码异常        v3 ❌
  ├─ μ+σ 凯利          v4 ❌（σ 学到了，μ 没学到）
  └─ 只用 σ            v5 ❌（σ 学准了，但 σ 不影响收益）
```

**五种表达方式全堵死。** 换成第六种表达方式，大概率还是堵。

剩下没试的信息维度：

| 维度 | 状态 | 拦在哪 |
|---|---|---|
| 跨币截面（502 币同时看） | 未试 | 需同步数据（有 `klines_1m_sync.csv`） |
| 更长历史（240 币 × 9 年） | 未试 | E 盘 49.68 GB 已在，未接 |
| 订单流（主动买/卖、大单） | 样本不足 | live 只录了 2 天 |
| 1s 粒度 | 样本不足 | live 只录了 2 天 |

**结论：下一步必须动"信息"，动"模型结构"是第六次重复。**

## 四、诚实边界

本轮只覆盖 **8 币 / 1 年 / 1.2 万~4.2 万参数 / 320~500 训练步**。

所以不能说"1m 价格量里不存在可交易结构"。
只能说：**这五种表达方式 × 这个规模下，没有提取到。**
