## 一、止盈 × 止损 二维穷尽：240 格全部为负

**口径**：V05=240min(4h)、V09=2880min、持有上限 1440min(24h)、成本 0.50%/笔、D01（60币/1年/1m）。
**网格**：止盈 +5%~+50%（步 3%，16 档）× 止损 −6%~−20%（步 1%，15 档）= 240 格。
**结果**（`tpsl_grid.csv` / `tpsl_grid_summary.txt`）：

| 项 | 结果 |
|---|---|
| **mean_all > 0 的格** | **0 / 240** |
| mean_all 中位 | −0.121% |
| mean_all 最好 | −0.032%（TP=14% / SL=−20%） |
| mean_all 最差 | −0.307%（TP=5% / SL=−6%） |
| mean_h3 > 0 的格 | 172 / 240 |
| mean_h3 最好 | +1.799%（TP=38% / SL=−10%，526 笔） |

### 1.1 最重要的两个读数

**读数 A：止盈越大，越接近 0。**

| 止盈档 | mean_all 范围 |
|---|---|
| +5% | −0.22% ~ −0.31% |
| +8% | −0.14% ~ −0.24% |
| +11% | −0.08% ~ −0.18% |
| **+14%** | **−0.03% ~ −0.14%** |
| +26% | −0.05% ~ −0.16% |
| +50% | −0.11% ~ −0.22% |

**止盈越小亏得越多。** 因为手续费按次数收：止盈 5% 时 0.5% 成本吃掉 10%，止盈 26% 时只吃 1.9%。

**读数 B：最优那一格其实是「不设线」。**

TP=38% / SL 从 −6% 扫到 −20%，结果几乎不变（+1.69% ~ +1.80%）——
**说明止损根本没触发过**。该格 TP率仅 **1.0%**，也就是说：
**99% 的单子既没到止盈也没到止损，全靠 24h 到期平仓。**

**结论：网格扫了 240 格，最优解不是某组 TP/SL，而是「别设线，持有到期」。**

## 二、成本结构：0.50% 是固定的，它按次收

| 项 | 单边 | 双边 |
|---|---|---|
| taker 手续费 | 0.10% | **0.20%** |
| 滑点（乐观估计） | 0.15% | **0.30%** |
| **合计** | — | **0.50%/笔** |

**maker 挂单：手续费 0.02% × 2 = 0.04%，滑点接近 0。两者差 0.46pp。**

### 2.1 盈亏平衡胜率

```
p* = (止损 + 0.5%) / (止盈 + 止损)
```

| 止盈 | 止损 | p* 门槛 | 成本占目标 |
|---|---|---|---|
| +2% | −1% | **50.0%** | **25%** |
| +5% | −2.5% | 40.0% | 10% |
| +8% | −4% | 37.5% | 6.3% |
| +14% | −7% | 35.7% | 3.6% |
| +26% | −12% | 32.9% | 1.9% |
| +38% | −19% | 34.2% | 1.3% |

### 2.2 胜率与赔率的硬约束

| 胜率 | 止盈 − 止损 至少要 |
|---|---|
| 60% | 可负（止盈 = 0.74~1.08 × 止损） |
| **50%** | **+1.0pp** |
| 40% | +2.5pp |
| 30% | +6.0pp |

**60% 胜率的数学含义：止盈可以小于止损，但要 > 0.74×止损 + 0.83pp。**

## 三、波动率能做什么、不能做什么

### 3.1 能做的三件事（数学）

**① 算「止盈该设多远」——首达概率**

```
到达概率 ≈ 2 × Φ( −d / (σ√t) )
```

| 想要的到达概率 | 目标距离 d |
|---|---|
| 50% | 0.67 × σ√t |
| 30% | 1.04 × σ√t |
| 20% | 1.28 × σ√t |
| 10% | 1.65 × σ√t |

**止盈正确形式是一个固定百分比，而是 σ√t 的倍数。**

**② 算「止损该设多宽」——噪声宽度**

| 止损距离 | 被噪声扫掉的概率 |
|---|---|
| < 0.5σ√t | 几乎必扫 |
| 1.0σ√t | 约三成 |
| **≥ 2.0σ√t** | 安全 |

**③ 算「现在是不是好时候」——波动聚集**

`sym_1m` 实测（vstd ≥ p99 档，n=11,808）：
- 涨 ≥2% 概率 **50.5%**
- 跌 ≥2% 概率 **61.8%**
- 摸到 +2% 后又跌破 −1% 占 **34.1%**

**波动大 = 机会多，但跌的机会比涨多。**

### 3.2 不能做的一件事

**判断方向。** `drift_1m` 实测：按 vstd 分档「涨概率」≈ 50%，波动大不改变方向。

### 3.3 关键缺口：项目一直用的是「成交量」波动率

代码事实（`gambler_h3_clean.py` / `gambler_momentum_baseline.py`）：

```python
vw = v[j - VW:j + 1]                                  # v = volume
v240 = np.std(np.log1p(np.maximum(vw, 0)))            # 成交量的对数标准差
```

| 类型 | 算的是什么 | 能预测 | 用过吗 |
|---|---|---|---|
| 成交量波动率（v240/vstd） | 成交量变化多剧烈 | 有没有行情（AUC 0.73） | ✅ 一直在用 |
| **价格波动率（σ）** | **收益率标准差** | **线该设多宽** | **❌ 从未计算** |

**「成交量放大」= 有人在动；「价格波动大」= 价格在跑。这是两件事。**

**要自动态止盈止损，需要后者；而后者这个项目一次都没算过。**

### 3.4 反面证据：动态止损试过，更差

`stop_dynamic`（job-149）四规则对比：

| 规则 | 均值 | 回撤 |
|---|---|---|
| **A 固定 −9.5%** | **+15.21%** | 0.487 |
| B 移动止损 | +14.61% | 0.487 |
| **C 波动率止损（−2×v240）** | **+12.58%** | 0.529 |
| D 仅时间止损 | +16.22% | **0.973** |

**按 −2×v240 定止损反而最差。** 原因推测：v240 是成交量波动率，与价格波动不同量纲，低波动时止损被收到极窄，被日常抖动扫掉。

## 四、小周期的定义：项目里有三种，互相冲突

| 出处 | 定义 | 持有 | 目标 |
|---|---|---|---|
| `gambler_merge.py` | 5m 跌 5% + 量比 ≥4 | **300 分钟** | +2% / −1% |
| `gambler_canonical.py` | 1h 粒度 + h3 筛选 | 60 分钟 | +5% / −2% |

**三者入场、持有、目标全不一样，却都叫「小周期」。**

### 4.1 本报告建议的统一定义

**用「持仓时长 × 目标收益」两维钉死：**

| 名称 | 持仓 | 目标收益 | 每年机会 | 实测结果 |
|---|---|---|---|---|
| 微周期 | 1~15 分钟 | +1%~2% | 数万 | **均负** |
| **小周期** | **15~120 分钟** | **+2%~8%** | 数千 | **负** |
| 中周期 | 2~8 小时 | +8%~20% | 数百~数千 | **+0.64%**（TP=11%，5,682笔） |
| 大周期 | 8~24 小时 | +20%~38% | 数百 | +0.30%~+1.80%（t 不足） |

## 五、小周期赚不赚钱：两条路都试过，都负

### 路 1：小周期的目标，配大周期的入场

| 止盈 | 笔数 | 扣费后均值 |
|---|---|---|
| +5% | — | **−0.22% ~ −0.31%** |
| +8% | 8,153 | **−0.14% ~ −0.24%** |

**全负。**

### 路 2：小周期的目标，配小周期的入场（急跌放量抄底）

| 测试 | 定义 | 首触止盈率 | 门槛 34.7% | 结论 |
|---|---|---|---|---|
| `tp2-1m` 系列 | 1h 跌 5% 入场，+2%/−1%，60min | 20~30% | 未达 | **负** |
| `gambler_merge` 1m | 15m 跌 5% 放量 | — | — | 50 → 46.71 元（**0.93x**） |
| `gambler_merge` 5m | 同上 | — | — | 50 → 31.15 元（**0.62x**） |

**全负。**

### 5.1 为什么「波动」本身不产生利润（数学）

**单向交易（现货/永续单边）里，波动只决定「多快到线」，不决定「先到哪一边」。**

设止盈 +TP、止损 −SL，价格布朗运动：

```
先触止损概率 = TP / (TP + SL)
先触止盈概率 = SL / (TP + SL)
期望 = SL/(TP+SL) × TP − TP/(TP+SL) × SL = 0
```

**纯随机下，任何 TP/SL 组合的期望都是 0，再扣 0.5% 必为负。**

**要正期望，必须有方向信息（h3 那种「状态」也算方向信息的弱形式）。波动率本身提供不了。**

### 5.2 想赚「波动」的钱，只有三种结构

| 结构 | 怎么赚 | 本项目能做吗 |
|---|---|---|
| 期权跨式/宽跨式 | 同时买涨和跌，波动大两头赚 | ❌ 无期权数据/权限 |
| 网格/做市（maker） | 靠买卖价差赚，成本 0.02% | ⚠️ 需要挂单成交率数据，现在没有 |
| **方向 + 波动择时** | 波动大时下注（方向仍要预测） | ✅ 这是现在的路 |

## 六、结论摘要

1. **止盈止损二维穷尽：240 格全部为负。最优不是某组值，而是「别设线」。**
2. **成本 0.5%/笔按次收，止盈越小越吃亏（5% 档吃掉 10%，26% 档吃 1.9%）。**
3. **波动率能算「线该设多宽」（σ 的倍数），不能算方向。**
4. **项目一直用成交量波动率，价格波动率从未计算——这是最大缺口。**
5. **小周期（+2%~8%）两条路都试过，都负。原因不是信号，是成本结构。**
6. **单向交易里，波动本身不产生利润；纯随机下任何 TP/SL 期望都为零。**
