# 资产 A2 · 日躁分钟静 + 买盘强 + 凌晨 做空组合（TP2/SL1）

> 状态：**已验证，冻结参数，作为资产保留**
> 建立日期：2026-10-17
> 证据文件：`evidence/cycle/exhaust_summary.txt`（穷举 1~4 条件后 Top1）
> 发现方式：43 信号 × 1~4 条件全枚举（136,697 个组合，无遗漏），非抽样

## 组合定义（精确，不可改）

做空（跌 = 赚），60 分钟窗口内：

| 条件 | 阈值 | 含义 |
|---|---|---|
| vstd | < p50 | 当前 1 分钟收益波动率低于训练段中位（此刻安静） |
| vstd1440 | > p90 | 24 小时波动率高于训练段前 10%（最近一天很躁） |
| tbr | > 0.7 | 主动买占比 > 70%（买盘强） |
| hour | ∈ [0, 6) | UTC 0~6 点（北京时间 8~14 点） |
| 止盈 TP | −2% | 价格跌 2% 平仓 |
| 止损 SL | +1% | 价格涨 1% 平仓 |

## 与资产 A1 的区别（两个独立机制）

| | A1 缩量急涨 | A2 日躁分钟静 |
|---|---|---|
| 触发信号 | 15 分钟急涨 +2% + 缩量 | 日波动高 + 分钟波动低 + 买盘强 |
| 触发率 | 87.2% | 60.3% |
| 三段稳定性 | 未做到三段全正 | **三段全正** |
| 滑点 0.3% 后 | +0.090% | **+0.246%** |
| 机制解释 | 拉高后缩量 = 买盘枯竭 | 躁动后安静 + 追涨买盘多 + 凌晨流动性差 = 容易被反杀 |

## 边界与未验证项

1. 样本 174 笔（60 天，约 3 次/天采样口径），比 A1 更小；
2. hour 0-6 是 UTC 时段，实盘需按当地时区换算；
3. 全流程零实盘，未计挂单成交率与延迟；
4. 滑点 0.5% 以上基本失效——只能 maker 挂单；
5. 存活偏差：数据里只有活到今天的币。

## 使用纪律

- 参数不得改动（改任一阈值需重新走三重验证）；
- A1 与 A2 可叠加使用（两条件同时满足时仓位可加大），但叠加后样本极小，需单独验证。
