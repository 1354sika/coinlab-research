## 0 用户定义（逐字）

> 「周期最长48h，上涨到百分之三十这个记录点之后还在涨就继续记录，直到跌出现，那么这个周期结束。
> 不是到百分之30就结束，30只是这个曲线的起点，当斜率让曲线下降，那么周期结束。」

实现规则：低点 L → 首次触及 L×1.30 = **认定点** → 继续涨一直记（peak 用 high） → 从 peak 回落 ≥R 或总长 >48h = **结束**。

### 三条反直觉的实测结论

1. **"4~5 小时翻几倍"在 5m K 线口径下不成立**：从低点涨到 +30% 的中位用时是 **18.7~24 小时**。4~5 小时只够走完"认定"之前的很小一段。
2. **认定之后只剩零头**：认定点（已涨 30%）之后的剩余空间中位只有 **+3%~+12%**。
3. **主升段全部发生在认定之前**：周期涨幅中位 34%~45%，而认定点只吃到其中的 30%。

⇒ 与用户"前期 = 认定前"的判断一致：**钱在认定前，认定后只能吃尾巴。**

## 2 高等数学的五个落点（当前模型的真实缺口）

现有全部工作都是**离散查表**：分档、组合、lift、概率。没有一个使用连续、可微、动态的语言。

| 数学工具 | 用户说的"斜率"对应什么 | 现有做法 | 缺口 |
|---|---|---|---|
| 一阶导 `p'(t)` | 斜率本身 | 用"24h 涨幅"这种区间差近似 | 中 |
| **二阶导 `p''(t)`** | **"斜率开始下降"** | **从未使用** | **大：加速度转负通常早于价格转跌** |
| 积分 `∫V dt / ΔP` | 拉升消耗的燃料 | 只用瞬时量比 | 大 |
| 微分方程（SIR） | 吸筹 → 拉升 → 派发 | 硬编码状态机 5 态 | 大 |
| 首达时间 / 最优停时 | "什么时候撤" | 网格搜 6 组止盈止损 | 大 |

### 2.1 融合映射（把已验证的结论串成一套方程）

| 已验证结论 | 在动力学模型中是什么 |
|---|---|
| 位置 `over_now`（置换重要性第一） | SIR 的**已感染比例 I/N** |
| fomo / panic（心理侧写） | **传染率 β**（跟风强度） |
| 成交量 / 累积成交额 | **燃料积分** |
| 蝴蝶效应时序链（A→τ→B） | **马尔可夫转移矩阵** |
| 周期成簇（距上次起局 ≤24h → 再起局率 51.7%） | **状态的记忆性**（非马尔可夫项） |
| 止盈止损 | **最优停时**的解 |

### 2.2 为什么这一步是"换判据"而不是"换工具"

若价格是随机游走，二阶导没有任何预测力（有效市场假说的内核）。我们的数据里若真有"局"，就意味着**漂移项随时间变化**。SIR 把这种非随机性参数化成 β、γ，于是"是否存在局"从一句断言变成一个**可检验的拟合问题**（拟合优度 / 残差检验）。
