# 赌徒退出机制设计（v0.1）

> 触发：用户证言「他的止损线和止盈线都是靠感觉的，所以导致到了本金的百分之五十之后又跌回了本金」（线索级，未签字）。
> 本文件只把**已跑过的实测**收成规格，未测的一律标「待验证」，不写成结论。

---

## 一、三条已有实证（决定机制该怎么设计）

| # | 命题 | 证据 | 结论 |
|---|---|---|---|
| A | **单笔层「预测退出时点」学不到** | `gambler_exit.txt`：反事实账本学到的退出表，740596 次查表 **0 次命中**，「学会的退出」与「固定 H」完全同值；`分析_峰值退出可达性_2026-10-19.md`：V14~V19 六版模型 AUC 0.516~0.660，决策全负 | 别在单笔上赌「这一根是不是峰」 |
| B | **组合层「净值回撤阈值」有效** | `cum50_REAL.txt` 第七节：同一序列，无规则 3 年终值 **0.0000x**；到 1.5x 后回撤 2%/5%/10% 清仓，分别锁定 **1.658 / 2.218 / 1.986 倍** | 退出要挂在**组合净值**上，不是单笔时点 |
| C | **目标口径 = 几十笔累计 +50%** | `cum50_REAL.txt` 第四/五节：40 笔窗口 14.4% 能到 1.5x；从任一时刻起中位 **1767 笔**才首次碰到，25% 分位 620 笔 | 这是低频、长等待的目标，机制必须能「等」 |

**A 与 B 不矛盾**：预测峰失败，但「峰后回撤多少就走」是纯规则，不需要预测。

## 二、机制设计：四层（从下到上）

```
L4 熔断层   净值 ≤ 1.0x（跌回本金） → 全停，本轮结束
L3 守护层   净值 ≥ 1.5x 后，从峰值回撤 f% → 全清停手   ← 核心
L2 止盈层   单笔固定 TP（1% / 2% / 3%）
L1 止损层   单笔固定 SL（待定，历史参照 -2%）
```

### L3 守护层（核心，唯一被实测证明有效的）

| 参数 | 取值 | 依据 |
|---|---|---|
| 进入条件 | 组合净值 ≥ 1.5x | 用户口径 100→150 |
| 触发 | 净值 < 峰值 × (1−f) | 回撤口径，非固定止盈 |
| f 默认 | **5%** | 2%/5%/10% 三档实测都锁 >1.5x，5% 处锁定值最高（2.218x），且不敏感 |
| 动作 | 全清 + 本轮停止交易 | 用户案例正是「到了 1.5x 没停」 |

### L2 止盈层（作用有限，勿当主力）

实测 TP=1%/2%/3% 三档每笔均值都是 **-0.110%**（`cum50_REAL.txt` 第一节）——单笔止盈线怎么调都不改变期望。**它只负责把「多次小赚」变成可结算现金流，不负责赚钱。**

### L4 熔断层

用户案例：到 1.5x 后跌回 **1.0x（本金）**。L4 就是这一条：跌回本金即全停，不再给「感觉会回来」的机会。

---

## 三、与用户案例的逐句对应

| 他的行为 | 机制 | 实测后会发生什么 |
|---|---|---|
| 止损止盈靠感觉 | 换成 L1/L2 的固定百分数 | 单笔期望不变（-0.110%），但行为可复现 |
| 到了本金 +50% 没走 | L3 进入守护，回撤 5% 清 | 锁定 2.218x，而不是回落到 0.0000x |
| 又跌回本金 | L4 熔断 | 到 1.0x 就停，不会继续 |
| 总共只做几十笔 | 目标按 hitting time 算：中位 1767 笔、25% 分位 620 笔 | 机制必须允许「长期等待 + 一次兑现」 |

## 四、待验证（下一轮该跑的）

1. **多币并发持仓**下的组合净值口径（本轮是单序列复利，实盘是 5 个币同时持）。
2. f 的稳定性：在 304 币池（小市值、流动性差）上重测 2%/5%/10%。
3. L1 止损线取值：-2% / -5% / 无止损 三档对比。
4. 分批止盈（50% 仓位在 +50% 出、剩余用 L3 守护）与全清的比较。
5. 熔断线设 1.0x 还是 1.1x（保留 10% 缓冲）。
6. 以上全部仍是零滑点、high 触价假设，成交率未计。

## 五、诚实边界

- 证据 A/B/C 均来自 60 币池、5m K、3 年、回测、零滑点、零成交率；304 币池未覆盖。
- L3 的 2.218x 是**理论复利值**，实盘受同时持仓数、保证金、流动性限制，不可直接照抄成收益预期。
- 用户证言为线索级，未签字，不作为事实引用。
