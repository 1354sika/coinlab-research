# gambler 端到端三版实测与诊断（2026-10-19）

## 一、三版共同遵守的定稿

| 项 | 定义（用户 2026-10-19 确认） |
|---|---|
| 形态 | **一个**赌徒，不做空，杜绝前视 |
| 输入 | 原始序列，无人工招式/专家列表 |
| 输出 | 连续仓位（买/卖/持） |
| 目标 | 周期复利 + 强制下注率下限 5% |
| 判据 | **只看样本外 + 打乱对照必须变差** |
| 数据 | `klines_1m_1y.csv`（30,157,400 行 / 60 币，本轮用前 8 币） |

## 二、三版结果对照（全部 8 币 × 1 年 1m，样本外 30%）

| 版本 | 核心机制 | REAL 期末 | SHUF 期末 | 判别力指标 | 判决 |
|---|---|---|---|---|---|
| **v1 `gambler_e2e`** | 每根输出一个仓位 | 0.8708 | 1.3011 | 仓位恒定 0.493 | ❌ SHUF > REAL |
| **v2 `gambler_yolo`** | 三头 obj/hold/size（标签=未来最优收益） | **0.0000** | 0.0000 | **obj AUC 0.5225**（SHUF 0.4888） | ❌ 无判别力 |
| **v3 `gambler_anomaly`** | 自编码器重构误差 = 当下异常（**无未来标签**） | **0.0000** | 0.0000 | MSE 0.736→**0.273**（学成了） | ❌ 异常≠机会 |

## 三、逐版诊断

### v1：模型停在初始化点
- 平均仓位 REAL 0.493 / SHUF 0.497，下注率 100% ⇒ **输出恒等于 sigmoid(0)=0.5**
- 根因：`-mean(段内对数收益)` 在段内均值≈0 时对仓位无梯度
- 两版收益差全部来自数据路径，与模型无关

### v2：objectness 学不到（AUC 0.52）
- `obj` 输出被压到 **0.497~0.517 的极窄带**，AUC 0.5225（打乱后 0.4888）
- `hold` 头预测 21 根，而标签平均 900+ 根 ⇒ **完全没学到**
- 唯一在学的是 `size`（损失 0.110→0.009），因为它学成了"全押"
- **概念错配（用户已裁定）**：YOLO 的 objectness 检测"当下就在输入里的东西"，我让它检测"只存在于未来的机会" = 变相预测

### v3：网络学成了，但学的东西不赚钱（**本轮最关键的证据**）
- 自编码器 MSE **0.736 → 0.273**，说明 11.8K 参数的网络**完全有能力**从原始 1m 序列里学到结构
- 但：REAL −100%，SHUF −100%，**两者几乎一样**
- 在场率 6.9%（异常分 top 3% 开仓），每根净收益 −0.00159%
- **结论：模型确实学会了"什么算异常"（重构误差下降），但"异常"与"未来收益"之间没有正向关系**

---

## 四、三版合起来的结论

**这是三件不同的事，指向同一个位置：**

1. v1 证明：**梯度设计错了，模型会原地不动**（工程问题，已修）
2. v2 证明：**"预测未来机会"在 1m 价格量上 AUC≈0.5**（信息问题）
3. v3 证明：**"描述当下状态"能学会（MSE 降 63%），但描述出来的东西不带来收益**（信息问题，且排除了"网络不够强"这个解释）

**合起来：1m 价格量里存在可被网络捕获的结构（v3 的 MSE 降幅为证），但该结构与未来收益无关。**

**换句话说：模型不是"学不动"，而是"能学的东西不值钱"。**

---

## 五、诚实边界（未完成 ≠ 否定）

- 本轮只跑了 **8 币 / 1 年 / 1.2 万~4.2 万参数 / 320~400 训练步**。
- **E 盘 240 币 × 最长 9.2 年数据完全未使用；60 币只用 8 个。**
- 因此不能说"1m 价格量里不存在可交易结构"，只能说：**在这一规模、这三种表达方式下，没有提取到。**
- 未做的对照：更大网络/更长训练（排除容量）、跨币截面（换信息）、1s 粒度（换分辨率）。

### v4 `gambler_odds`：预测(μ) + 赔率(σ) 一起搞（用户 2026-10-19 裁定方向）

一条网络双头，学收益的**整个分布**（高斯 NLL，不是学点）：
`L = (r-μ)²/(2σ²) + logσ`；仓位由凯利算出：`w = clip((μ-c)/σ², 0, 1) × 0.25`。

| | REAL | SHUF |
|---|---|---|
| μ 均值（训练收敛值） | +0.0098 | −0.0092 |
| σ 均值（训练收敛值） | 0.0163（真值约 0.007） | 0.0176 |
| **IC(μ vs 未来收益)** | **+0.0005** | +0.0023 |
| 平均仓位 | **0.9890（满仓）** | 0.1585 |
| 期末资金 | **0.0002** | 0.0000 |
| 四段 | 0.3083 / 0.5739 / 0.0750 / 0.0117 | 全 0.0000 |
| 盈利币 | 0/8 | 0/8 |

**诊断（本轮最重要的三条）：**

1. **σ（赔率）学对了。** σ 从 1.0 收敛到 0.016，与真实未来 60 根收益 std（0.47%~1.43%）同量级 —— **证明"实时赔率"这一半是能学出来的。**
2. **μ（预测）学不到。** IC = **+0.0005**（打乱后 +0.0023，几乎相同）—— μ 与未来收益的相关性为零。
3. **凯利把 μ 的误差放大成灾难。** 训练段均价上涨 ⇒ μ 学成 +0.0098（约 +1%），测试段实际 −0.01% ⇒ `(μ-c)/σ²` = (0.0098−0.0004)/0.0163² ≈ **35**，被 clip 到 1 ⇒ 满仓 ⇒ 爆仓。

**结论：赔率能学，预测学不到；而当 μ 不准时，凯利公式不是"仓位管理"，是"误差放大器"。**

### v5 `gambler_vol`：只用赔率，不要 μ（用户 2026-10-19 裁定方向）

单头网络只学 `logσ`（μ 固定为 0），仓位 `w = clip(target/σ, 0, 1)` —— 纯波动率目标 / 风险平价。

| | REAL | SHUF |
|---|---|---|
| σ 训练收敛 | **0.0096**（真值约 0.007） | 0.0086 |
| 平均仓位 | 0.8345 | 0.6619 |
| 期末资金 | **0.0000** | 0.0000 |
| 四段 | 全 0.0000 | 全 0.0000 |
| 盈利币 | 0/8 | 0/8 |

**关键诊断（脚本内置的"低波 vs 高波，未来收益谁更高"）：**

| 币 | 低波动时未来收益 | 高波动时未来收益 | 谁更好 |
|---|---|---|---|
| DOGE | +0.00719% | −0.00303% | 低波 |
| BTC | +0.01016% | +0.01646% | **高波** |
| SOL | +0.01053% | +0.01074% | 持平 |
| ETH | +0.01266% | +0.01942% | **高波** |
| TRUMP | −0.00789% | +0.02873% | **高波** |
| XRP | +0.00525% | +0.02047% | **高波** |
| PEPE | +0.02362% | +0.00965% | 低波 |
| FF | +0.03108% | +0.00743% | 低波 |

**8 币：3 个低波更好、4 个高波更好、1 个持平 —— 方向不一致，"低波动异象"在这份数据上不成立。**

**结论：σ 估准了（0.0096 vs 真值 0.007），但"波动低 → 收益高"不成立，所以 `w = f(σ)` 与收益无关 ⇒ 仓位退化成"接近满仓的买入持有"，样本外吃下跌就爆。**

## 六、冻结的判据（下轮仍用，不改）

1. 样本外期末资金 > 1
2. 打乱对照必须明显更差
3. `obj`/判别头 AUC（样本外）> 0.55
4. 四段同正
5. 下注率 ≥ 5%
