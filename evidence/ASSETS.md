## 资产 B：前兆筛选（筛掉 38% 假启动）

**规则**（脚本 `scripts/gambler_presignal.py` / `gambler_real100.py`）

在「涨 3% 入场」那一刻，用 **入场根可知** 的特征预测「这笔会不会到 +30%」：

| 特征 | 含义 | 单特征 AUC |
|---|---|---|
| **v240** | 近 240 根 5m 收益率标准差（波动） | **0.784** |
| **pos** | entry / lo（离低点多远） | **0.729** |
| lo_age | 低点到入场经过的 5m 根数 | 0.753（反向） |
| r1 / r15 / r60 | 入场前 5m / 1h / 3h 涨跌 | 0.67 / 0.66 / 0.65 |
| tbr | taker 买占比 | 0.588（反向） |
| volr | 量比 | 0.575 |
| hour / dow | 小时 / 星期 | 0.58 / 0.53 |
| hist3 / hist10 | 本币近 3/10 次启动 TP 率 | 0.54 / 0.55（几乎无用） |

**判别效果**（测试段，时间后 50%）

| 档 | 笔数 | 实际到 +30% | 相对基准 |
|---|---|---|---|
| P < 0.3 | 1,071（38%） | **30.9%** | 0.53x |
| P 0.3~0.5 | 349（12%） | 45.3% | 0.77x |
| P ≥ 0.5 | **1,380（49%）** | **83.7%** | 1.42x |
| P ≥ 0.7 | 1,064 | 83.8% | — |

**AUC = 0.780 ~ 0.783**（`presignal_summary.txt` / `real100_summary.txt`）

**用途**：**P < 0.3 的 38% 直接不做**——这些启动 70% 走不到 +30%，做了就是送钱。

## 组合起来（本金 100 的模拟）

**规则**：资产 A 的入场/止盈/止损 + 资产 B 的 P≥0.5 筛选，逐笔 10% 仓位复利。

| 项 | 值 |
|---|---|
| 交易笔数 | 1,380（测试段 1.5 年） |
| 胜率 | 79.3% |
| 单笔均值（扣成本前） | +11.49% |
| **单笔均值（扣成本后）** | **+10.99%** |
| **最大回撤** | **64.88%**（扣成本后） |
| 最差单笔 | −76.5% |
| 理想复利结果（扣 0.5%/笔） | 100 元 → **294,516,836 元** |

**成本口径（强制，所有模拟必须扣）**：每笔 taker 0.10%×2 + 滑点 0.15%×2 = **0.50%**。低档口径 maker 0.02%×2 + 滑点 0.05%×2 = 0.14%。

**⚠️ 最后一行不可当真**：见 `real100_summary.txt` 判读——未扣滑点、未算容量。复利数学正确，但资金到千万级后 58 个币的盘口吃不下。**可采信的是前三行：胜率 79.3%、单笔 +11.49%、回撤 61.42%。**
