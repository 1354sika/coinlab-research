# 《67 倍》核心设计：三选择机制

> 2026-10-20 草案。设计目标：**不强制玩家赌，但让玩家看见"不赌也是一种赌"。**

## 一、每关三个按钮

| 按钮 | 玩家以为 | 实际发生 |
|---|---|---|
| **下注** | "我按策略来" | 延迟 2.54 秒 + 成本 0.25% + 止损被打穿 |
| **不赌** | "我躲过了" | 系统展示：这关如果赌了会怎样（赢/输都有） |
| **退出** | "我不玩了" | 系统展示：你离开期间市场发生了什么（机会成本） |

**三个按钮都不是"安全"的——这正是设计核心。**

## 二、"不赌"的代价（真实数据支撑）

| 场景 | 真实数字 | 游戏表达 |
|---|---|---|
| 空仓的机会成本 | 3m跌3% 一年 1305 笔、+23.7% | "你跳过的这 1305 次，值 237 元" |
| 持有现金的通胀 | 假设年通胀 2% | "你手里的 1000 元，一年后值 980 元" |
| 不参与的后悔 | gambler_psych：61.8% 的峰在 +50~58% | "你错过了 61.8% 的人都能抓到的那个位置" |

## 三、核心反转（游戏的高潮）

**玩家玩到第 N 关时会发现：**

```
玩家以为：我在"赌"和"不赌"之间做选择
实际情况：两个选择都在赌
  下注 = 赌"这次会涨"（期望 +0.19%/笔，但要扣成本）
  不赌 = 赌"这次不会涨"（期望 = 0，但要扣机会成本）
```

**最后的结算：**

| 玩家策略 | 一年后 | 说明 |
|---|---|---|
| 一直下注 | 300~1500 元 | 大数定律生效：期望正但方差大 |
| 一直不赌 | ~980 元 | 通胀 + 机会成本 |
| 时而赌时而不赌 | 取决于纪律 | **最接近"人"的行为** |
| 到 +50% 就走（纪律版） | **1091 元** | 我们实测的最优解之一 |
| 贪（到 50% 不走） | **0.0156 元** | gambler_odds 的 126 万次结果 |

**关键：没有一个策略能到 100 万。**

## 四、为什么不强制 = 合规更安全

| 设计 | 合规风险 | 理由 |
|---|---|---|
| 强制玩家必须下注 | **高** | 接近"赌博游戏"定义 |
| 可跳过、可退出、有代价 | **低** | 是"选择"，不是"强制" |
| 明确展示反赌结论 | **低** | 教育定位 |

**《恶魔轮盘》你必须扣扳机——那是"强制"。我们的设计是"你可以不扣，但你会看见后果"。**

## 六、待补的实验

**目前"不赌的代价"没有实测数据。** 要做：

1. 空仓一年的机会成本（用历史数据算：如果 2025 年什么都不做，1000 元变多少）
2. "跳到第 N 关"的后悔值（如果玩家跳过的关卡平均收益多少）

**这两条是游戏叙事的关键支撑，目前缺失。**

## 七、诚实边界

1. "空仓的机会成本"未做实验，上文数字是估算。
2. "通胀 2%"是假设值，未核实当前实际通胀率。
3. "时而赌时而不赌"的收益未模拟，只是直觉判断。
4. 游戏"好玩"程度完全未验证。
5. 上文引用的真实数据均来自 `coinlab/evidence/` 下的 txt 文件，可核。
