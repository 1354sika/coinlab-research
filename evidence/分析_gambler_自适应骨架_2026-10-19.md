# gambler 自适应骨架（粒度自由版）· 2026-10-19

> 用户口径（2026-10-18 末）：
> "自适应是肯定可以的……只能说我们现在的自适应参与方式不对，或者实验太少。
>  **模型不应该是只从三个挡位上选择回看多久，而是想看多久都行，粒度自由。**"
>
> 本版按此改：回看窗口从离散 3 档 → **12 个细尺度 + 连续 τ 核混合**。
> 全部为回测，零实盘，未计滑点与 maker 成交率。

## 一、改了什么

### 1. 回看粒度自由（核心）

```
12 个尺度：15 / 30 / 60 / 120 / 240 / 480 / 960 / 1440 / 2880 / 5760 / 11520 / 23040 分钟
权重：    w_i ∝ exp(−(ln w_i − ln τ)² / 2σ²)，σ=0.7
τ：       连续，[15, 23040] 分钟，在线做 ln 空间扰动更新
```

模型实际选出来的 τ：**中位 322~379 分，范围 230~506，出现 9~23 个不同取值**——
确认不再是"3 个档位"，是连续粒度。

### 2. 修掉上一版 4 个错误

| 错误 | 修法 |
|---|---|
| 隐性杠杆：每笔按 100% 资金复利，同期最多 6 仓 ⇒ 600% 暴露 | 每笔固定用 1/6 资金，总暴露 ≤ 100% |
| 打乱对照算了没接上（SCORE2 从未使用） | 真序列 / 打乱序列各跑一遍完整回测，并排输出 |
| 参数跨期不可比（A 组 1 月、B 组 3 月混比） | 只用**最近 30 天**已结算交易比较 |
| 止损止盈公式拍脑袋（`max(1, held/60)`） | 改成过去 1 天收益的 3% / 97% 分位 |

### 3. 两个曾经致命的技术 bug（已修）

- 参数永远不换：最初没有强制探索，18 组参数里有效样本永远是 0，模型卡在初始参数（换过 0 次）。改为"先补足每组最低样本数，再比优劣"。
- 无任何交易：`enough = nv >= max(10, S//2)` —— 6 币时有效币最多 6，**永远凑不够 10**，牌全是 nan。改为 `max(2, S//2)`。

## 三、结论（诚实）

1. **骨架是通的**：粒度自由已实现（τ 连续、9~23 个不同取值）；三动作（多空双向）在跑；参数在线更新在跑；每 24h 用最近 30 天已结算交易重选。
2. **但它选出来的东西不赚钱，而且越多币越差**：20 币单笔 −0.0012%（t=−0.08）；**全量 60 币单笔 −0.0297%（t=−3.61），资金只剩 0.1036，回撤 −94.2%**。币越多，同时开仓越多，噪声选择被放大。
3. **自适应不如固定参数**：v1 固定参数 +36.9% 资金，v3 自适应 −7.7%。这不是"自适应没用"，是**当前的选择机制在噪声里挑最优**：
   - 每组参数只有 8~20 笔已结算样本，`均值 − 1.5×标准误` 这个判据在这种样本量下基本随机；
   - 20 币跑 4 个月只换了 8 次参数——探索预算被"补样本"吃光。
4. **打乱对照这一版不可用**：SHUF 单笔 −27%，资金归零。原因是 `shuffle_panel` 用 `exp(cumsum(打乱后 log 收益))` 重建价格，525k 步累积漂移会把价格压到 0（块重排后连续负收益段被放大）。**这个 bug 也影响此前所有基于该打乱的强结论**，需要修完再复核。

## 四、为什么"自适应"目前没用（诊断）

已验证的牌本身只有 **0.07%/笔** 的信息量（gate_cross，扣费前）。骨架再怎么选参，只能在这 0.07% 里分档，不可能凭空放大。自适应能做的是"在不同市场状态下挑最合适的用法"，但当所有用法的期望都是 0 附近时，挑哪一个都是 0。

换句话说：**自适应是放大器，不是发电机。** 现在缺的是电压（牌面信息量），不是放大幅度。

## 五、下一步（按价值排序）

1. **修 shuffle_panel 的价格重建**（差分重排 + 保持总漂移，或用块内相对收益），修完复核 v3 与之前 gate_cross 的结论。
2. **把持有期放长**：已验证 H=480 分时最高档 +0.507%（t=2.24），H=1440 分 +1.143%。当前 v3 的 H 网格里 480/960 很少被选中，应给长持有更多预算。
3. **参数选择改集成**：不是选一组最优，而是按后验权重同时用多组（这天然抗噪声，也符合"游刃有余"）。
4. **换原料**：订单流/盘口要等 live-recorder 攒够 2~4 周；E 盘 502 币 1m 在补（当前约 5 GB / 目标数百 GB），补齐后可做多年复验。
