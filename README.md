# 赌徒博弈

> 用 9 年 Binance 现货 1m 数据，系统测试「能不能靠算法在币市稳定赚钱」。
> 结论：**能找到正期望的规律，但扣掉成本后量级很小（年化 10~25%），且回撤极深。**

## 最好的年化结果

成本按 **0.25% 往返**（maker 费 + 0.1% 往返滑点），299 币，2017-08 ~ 2026-10，
信号族固定为 **15 分钟跌 5% 后买入，TP 3% / SL 1%**（前轮扫描出的最优盈亏比）：

| 配置 | 年化 | 最大回撤 | Calmar（年化÷回撤） | 笔/年 |
|---|---|---|---|---|
| 池 2（每笔半仓） | **51.03%** | **−95.09%** | 0.54 | 2,966 |
| 池 4（每笔 1/4 仓） | **45.60%** | −59.91% | 0.76 | 3,337 |
| 池 50 | 12.46% | −6.25% | **1.99**（最高性价比） | 4,301 |

**怎么读这张表**：池越小越猛、回撤越深；池越大越稳、年化越低。
想要最高年化选池 2，想要最抗揍选池 50。

**必须知道的诚实边界**：
- 51.03% / 45.60% 是在 **299 币全池**上跑出来的；换成标准池（字母序前 60 币）模拟，
  同一参数结论变成 **−99.35%、回撤 −100%**（见 `evidence/decompose_pool4.txt`）。
  **即：这两个数字依赖币池选择，不是任何币池都能复现。**
- 成本升到 0.35% 往返时，45 组里只有 4 组年化为正。
- 全部是回测，零实盘；成交率完全未模拟、权益未计浮亏、已下架归零币不在池内。

本仓库只放**结论、证据、脚本**，不放原始行情数据（原始数据 > 800 MB）。

## 一、这个项目在问什么

1. 能不能在价格最高点附近「完美退出」，把浮盈落袋？
2. 能不能靠「急跌后买入 + 止盈止损」这类机械规则获得正期望？
3. 4 到 20 个仓位并发、单账号、24 小时无人值守，长期复利能到什么量级？

## 二、核心结论（全部为回测，零实盘）

| 问题 | 结论 | 证据文件 |
|---|---|---|
| 完美退出能实现吗 | **不能**。理论上界 3.574%/笔；晚 1 根收盘卖降到 2.070%；跟踪止盈 θ=1.0% 现实只有 0.053%，离峰中位 -2.31%（差 67 倍） | `exit_peak_REAL.txt` |
| 加长最短持有能救吗 | **不能**。minhold 从 1 加到 12/24，收益不升反降 | `exit_peak2_REAL.txt` |
| 急跌后买入有正期望吗 | **有**，且跌得越狠越好（1s 跌 1% > 0.8% > 0.5%；15m 跌 5% > 2%） | `three_fixes.txt`、`strategy_1s.txt` |
| 最优盈亏比 | 3:1（TP 3% / SL 1%），15m 粒度、299 币、成本 0.25% 下年化 45.6%（**不可复现，见下**） | `grid3.txt` |
| 为什么不可复现 | 换成字母序前 60 币标准池模拟：年化 **-99.35%**，回撤 -100%，2021 年归零 | `decompose_pool4.txt` |
| 成本敏感性 | 0.25% → 年化 +23.7%；0.35% → 约 +11%；0.45% → 约 0% | `final_board.txt`、`slippage_sensitivity.txt` |
| 止损被打穿有多严重 | 实际止损笔平均亏 -1.89%，比名义 -1% 多亏 0.89pp；**打穿吃掉了每笔 -0.586%**（占收益差的 147%） | `sl_pierce.txt` |
| 盘口能容纳多大资金 | 卖 1000 USDT 中位滑点 0 bp；卖 5000 USDT 才 0.79 bp（仅主流 30 币） | `depth_impact.txt` |
| 网络延迟多大 | HTTP RTT 中位 308 ms；live_recorder 轮询 2 s；端到端最坏 2.54 s | `latency.txt` |
| 1s 尺度认峰可行吗 | **样本太少无法判定**。4 天 30 币，正样本 6~9 个，最强特征 big AUC=0.310 CI[0.214,0.405] | `live_peak_probe4.txt` |

## 三、被排除的方向

- **追涨**：三族 9 年两段皆负
- **放量增强**：零或负贡献
- **high 触价 +8%/笔**：收盘确认后降到 +0.54%
- **日停手**：不提升终值
- **落袋保复利**：收益砍 50%~80%
- **扩大币池**：池 200 年化仅 4.12%
- **全仓复利**：理论 184 倍/年 vs 实测 1.44 倍
- **导数出场**（一阶导转负/二阶导转负）：触发太早，中位第 2~5 根就走
- **σ 自适应止损**：k=2.5 胜率 37.9% 但终值反降
- **时间尺度交叉**：最优「止损 240m 确认 / 止盈 5m 确认」终值 2.13x，但样本内

## 四、还成立的规律（时间切分两段同号为正）

1. **急跌后买**：21/23 组在前后两段都为正
2. **跌得越狠越好**
3. **3:1 盈亏比优于其它比例**

## 六、诚实边界（读结论前必须看）

1. **全部为回测，零实盘验证。**
2. 成本按 0.25% 往返线性近似；真实滑点与金额、盘口深度、下单时刻强相关，急跌时更差。
3. **成交率完全未模拟**：急跌时挂 maker 单可能根本不成交，真实信号数与收益都会变。
4. 权益只计已平仓盈亏，**未计浮亏**，真实回撤更深。
5. 已下架归零币不在池内（**幸存者偏差**）。
6. 样本重叠：同一波行情可能被多次计数。
7. 极端终值（>1e10）是 9 年复利 + 零滑点的数学产物，**不可当预测**。
8. 未模拟交易所最小下单量、资金费率、API 限频、风控。
